# 设计规范（源自 Sketch 稿）

> 来源：`设计文件 (1).sketch`（Sketch 168 / 2025.1.3）

> 说明：本文由 Sketch 源文件的 JSON 直接解析得出，颜色/字号/坐标为设计稿原值。

## 一、整体风格

**深色 · 平面 · 广播图形感（broadcast-graphic）**

| 特征 | 具体表现 |
|---|---|
| 底色 | 近黑深灰 `#0E0E12`，卡片 `#17171F`，无多层渐变堆叠 |
| 描边 | 极细 1px 实线 `#2A2A36`，浅色描边用 `#FFFFFF @8% / @12% / @20%` |
| 阴影 | **完全不用阴影**（全稿 0 条 shadow），靠描边和底色分层 |
| 圆角 | **全部 0 圆角**（无 `fixedRadius`）——按钮、卡片、标签、chip 全是直角 |
| 强调色 | 单一主色 `#E4002B`（阿森纳红），只用于激活态 / 主按钮 / 关键数值 |
| 字体 | **Inter** 单一字族，5 个字重，无衬线 |
| 网格 | 1440 稿宽，**内容区 1280**（左右各 80 留白） |

> 注意：连"pill 标签"（赛事/主客/chip）都是**直角矩形**，不是圆角胶囊；队标也是**直角方章**（品牌色底 + 3 字母缩写 + 1px 白描边），设计稿里**没有使用真实队徽图片**。

## 三、字体规范

**字族：Inter**，字重 5 档：`Regular 400 / Medium 500 / Semi Bold 600 / Bold 700 / Extra Bold 800`

### 字号阶梯（12 档，建议直接作为设计令牌）
`44 · 32 · 26 · 22 · 20 · 17 · 16 · 15 · 14 · 13 · 12`

| 字号 | 字重 | 用途 | 出现次数 |
|---|---|---|---|
| **44** | ExtraBold | 首页主视觉大标题 | 1 |
| **32** | ExtraBold | 内页页面标题 | 1 |
| **26** | ExtraBold | 倒计时数字 | 4 |
| **22** | ExtraBold / Bold | 区块标题、对阵双方队名、速览数值 | 9 |
| **20** | Bold | 新闻头条标题 | 1 |
| **17** | Bold | 快捷入口卡片标题 | 4 |
| **16** | ExtraBold | 品牌名 "阿森纳足球俱乐部" | 3 |
| **15** | Bold / Medium / Regular | 表格行主文字（队名/比分）、正文说明 | 33 |
| **14** | Bold / Medium | 导航项、按钮文字、月份标题、名次 | 42 |
| **13** | Regular / SemiBold / Medium | 表体次要信息、日期、说明、链接、页脚链接 | 61 |
| **12** | SemiBold / Medium / Regular / Bold | 表头、标签、时间戳、状态、版权 | 95 |

**对比度**：最大字 44 与最小字 12 之比 ≈ **3.7 : 1**（非常克制）。中文正文最小不低于 12。

> 中文渲染：Inter 无中文字形，中文需接 `Noto Sans SC` / 系统字体兜底；数字与英文交给 Inter。
